 Advanced Data Analysis and Visualization in Logistics

Project Overview:

This project focuses on Exploratory Data Analysis (EDA) and data visualization using a hypothetical logistics dataset. The objective is to analyze delivery times, shipment volumes, transportation costs, and regional delays to understand logistics performance and identify potential operational bottlenecks.

Objectives:

- Perform data cleaning and exploratory data analysis.

- Analyze delivery time distributions and statistical measures such as mean and median.

- Examine the relationship between shipment distance and transportation costs.

- Compare transportation costs across different transport modes.

- Identify regional differences in shipment delays.

- Create visualizations to communicate insights and support data-driven decision-making.

Tools and Technologies:

- Python

- Pandas

- NumPy

- Matplotlib

- Jupyter Notebook / Python Script

- GitHub

Dataset:

The project uses a simulated dataset containing shipment details, delivery times, distances, transportation costs, transport modes, and operating regions. The dataset is hypothetical and is intended for learning and demonstration purposes.

Visualizations:

The project includes charts for:

1. Delivery time distribution

2. Average transportation cost by transport mode

3. Relationship between distance and transportation cost

4. Average shipment delays by region

5. Correlation between key logistics variables

Key Insights:

- The average delivery time is approximately 10.41 days in the simulated dataset.

- Shipment distance shows a positive relationship with transportation cost.

- Delivery delays and transportation costs can vary across regions and transport modes.

- Visual analysis can help identify areas for further investigation and operational improvement.

How to Run the Project:

1. Download or clone this repository.

2. Install the required Python libraries:
pip install pandas numpy matplotlib

3. Run the Python script:
python week3_logistics_eda.py
